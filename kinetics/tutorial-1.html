Question 1

Iodine reacts with propanone in acid solution as follows.

I2(aq) + CH3COCH3(aq) → CH2ICOCH3(aq) + H+(aq) + I−(aq)

The rate of reaction may be followed by measuring the concentration of the iodine using a colorimeter. An experiment was carried out at 50 °C using the following concentrations of reactants.

[I2] = 0.0020 mol dm−3; [CH3COCH3] = 0.10 mol dm−3; [H+] = 0.10 mol dm−3

Under these conditions, the rate equation is

rate = k[I2]0[CH3COCH3][H+]

and the rate constant, k, for the reaction is 5.0 × 10−4 mol−1 dm3 s−1.

This rate equation is consistent with the following mechanism for the reaction.

CH3COCH3 + H+ ⇌ (CH3)2C=OH+ (fast equilibrium)

(CH3)2C=OH+ → CH2=C(OH)CH3 + H+ (slow, rate-determining step)

CH2=C(OH)CH3 + I2 → CH2ICOCH3 + H+ + I− (fast)

  1. Calculate the initial rate of reaction.
  2. Plot a graph to show how the concentration of iodine changes during the first 200 s of the reaction.
  3. On the same axes, plot another graph to show how the concentration of iodine would change if its initial concentration were 0.0015 mol dm−3 (the other reactants being at the same initial concentrations).
  4. Suggest how the order with respect to the stated compound in the rate equation would alter when the concentration changes below are made. Give a reason for each case.

(i) With respect to I2, when the iodine concentration is very small.

(ii) With respect to H+, when the hydrogen ion concentration is very large.

Another experiment was carried out at the same temperature using the following concentrations.

[I2] = 0.010 mol dm−3; [CH3COCH3] = 0.0080 mol dm−3; [H+] = 1.0 mol dm−3

(e) The concentration of propanone decreased exponentially. Calculate the times for the concentration to fall to 0.0040, 0.0020 and 0.0010 mol dm−3. Use these values to plot a graph of concentration against time.

(f) On the same graph, plot how the concentration of iodine varies with time.

(g) Discuss how the successive half-lives of the reaction would change if the initial hydrogen ion concentration were 0.10 mol dm−3 rather than 1.0 mol dm−3.

2HgCl2(aq) + C2O42−(aq) → 2Cl−(aq) + 2CO2(g) + Hg2Cl2(s)

The following initial rates were measured at a fixed temperature.

Expt[HgCl2] / mol dm−3[C2O42−] / mol dm−3Initial rate / mol dm−3 s−1
10.1050.1501.80 × 10−5
20.1050.3007.10 × 10−5
30.05250.3003.50 × 10−5
  1. Deduce the order of reaction with respect to each reactant. Show your reasoning.
  2. Write the rate equation and calculate the rate constant, giving its units.

Question 3

The decomposition of hydrogen peroxide, catalysed by iodide ions, is first order with respect to H2O2:

2H2O2(aq) → 2H2O(l) + O2(g)

In one experiment, [H2O2] fell from 0.80 mol dm−3 to 0.20 mol dm−3 in 32 minutes.

  1. Determine the half-life of the reaction.
  2. Calculate the rate constant in s−1.
  3. Calculate [H2O2] after 80 minutes.
  4. Calculate the initial rate of the reaction.
  5. Suggest a suitable method for following the rate of this reaction.

Question 4

Nitrogen dioxide reacts with fluorine: 2NO2(g) + F2(g) → 2NO2F(g). Experimentally,

rate = k[NO2][F2]

Two mechanisms are proposed.

Mechanism A NO2 + F2 → NO2F + F (slow); NO2 + F → NO2F (fast)

Mechanism B 2NO2 ⇌ N2O4 (fast); N2O4 + F2 → 2NO2F (slow)

  1. Show that both mechanisms add up to the overall equation.
  2. State, with a reason, which mechanism is consistent with the rate equation.
  3. Write the rate equation that the other mechanism would predict.
